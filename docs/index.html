Casual Yumi

Casual Yumi

Matte, soft-touch components for Jetpack Compose, modelled on a TV remote.

I wanted a clean, modern, elegant design, and the Chromecast remote gave me the inspiration: round soft keys that sink when you press them, a big ring on top, and one key that stands apart from the rest. I made that key orange and turned the whole remote into Compose components.

Install See all 76 parts GitHub

Install

Served by JitPack. No account, no token. Your app needs compileSdk 37 (Compose 1.12).

settings.gradle.kts

dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven("https://jitpack.io")
    }
}

app/build.gradle.kts

dependencies {
    implementation("com.github.vladlazarean.casual-yumi:yumi-components:0.0.9")
}

Wrap your app

YumiTheme(accent = YumiAccent.Orange) {
    YumiButton(onClick = { }, variant = YumiButtonVariant.Accent) {
        Text("Dismiss")
    }
}

Four rules

Every component follows them. Learn them once and the whole library behaves the same way.

07:30

Raised means press it

Recessed means read it. A tray never takes a tap.

Orange is scarce

One accent action per screen, plus the lights that say something is on.

Selected means sunk

Selected keys rest pushed in with orange ink. Never an orange fill.

A press is a sink

Keys drop and swap their shadow. No ripples anywhere. Disabled keys rest sunk.
